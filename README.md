# Recipe Lab Studio

> 为 **Recipe Lab**（RL，索尼相机上的滤镜 app）制作和管理滤镜的 **电脑端程序**。
> 官方发布页：<https://github.com/jjingith/recipe-lab-studio-sony-pmca>

把相机用 USB 连到电脑、设成「大容量存储」，就能在电脑上：从一个 `.cube` 文件**或**一组摄影作品图，
拟合出风格相近的 RL 配方，实时预览套用效果与残差，存进 PC 主库，再**一键推送到相机存储卡的
`RECIPES\` 文件夹**——不用再在相机上一条条捏。

> 背景：RL 的自定义配方只存在存储卡上（`RECIPES/*.YML`），换卡即丢。本程序把 PC 当**真源**，卡是同步目标。

---

## 前置条件

1. **相机上要装一个「带自定义配方功能」的 RL 版本。**
   本程序做出来的就是这种自定义配方（`RECIPES\*.YML`）。
   基于老版本 RL **1.3.6** 的汉化版**没有自定义选项**，读不到本程序写进去的配方——请换用
   [recipe-lab-sony-pmca-cn](https://github.com/jjingith/recipe-lab-sony-pmca-cn)
   这类**含自定义配方 + 中文界面**的版本。
2. **Windows 电脑**；相机用 USB 连接并设为 **Mass Storage（大容量存储）**。此时存储卡会挂成一个
   盘符，根目录带 `DCIM\`，本程序据此自动识别相机卡。
3. **不连相机也能用**：导入、拟合、预览、PC 主库都与相机无关，只有「卡同步」需要相机在线。

## 功能

### 1. 三种「追色目标」来源

| 来源 | 怎么用 | 精度 |
|---|---|---|
| **导入 CUBE** | 载入一个 `.cube` 3D LUT，作为要**精确**套用的追色目标 | 预览精确（直接套用 LUT） |
| **追色目标作品** | 给一组照片（例如某位摄影师的一批作品），估计其整体风格 | 跨场景统计近似，与实际拍摄场景越接近越准 |
| **配对反推** | 给「原片 + 成片」两张**同机位**照片，用差异法反推调色风格 | 抵消场景本身，比上面更聚焦 |

> 「配对反推」的算式是 `目标 = 参考帧外观 + (成片 − 原片)`。两张图必须是**同一机位同一场景**
> （一次拍两张，或同一张的虚拟副本），否则这个差值就不是风格。鼠标悬停在该按钮上有同样说明。

### 2. 拟合 RL 配方

约束搜索，只在 RL 仓库自带的 **77 张标定样片**覆盖的参数范围内求解（**内插，不外推**）。
12 个可调字段全部按相机值域约束，越界即时拦截——因为**越界的配方会被相机静默跳过，等于白写**。

### 3. 预览与残差评分

- **预览**：左「原图」、右「目标效果」（cube 精确 / 配对成片 / 配方近似），下方一行残余 Lab 读数。
- **缩放 / 平移**：滚轮以光标为中心缩放（1.0x–16x）、拖拽平移、双击复位；两个预览框共享同一视区。
- **对比视图**：切为单屏，拖动中线在「原图 / 结果」之间擦除（双击中线复位到 0.5）。
- **分项评分**：把单一残差拆成五项读数——明暗(ΔL) / 饱和(ΔChroma) / 冷暖(Δb) /
  肤色（暖中间调窗口内的 ΔLab）/ 高光阴影（按参考帧亮度分带后的 ΔL），并给出置信度与校准状态。

### 4. PC 主库

`library\` 是**真源**：`index.json` 保存来源 / 标签 / 收藏等元数据，支持搜索、查重、历史版本
（`library\.history\`，保留最新 20 版，可一键还原）。内置 81 条 RL 官方配方可直接取用。

### 5. 卡同步（写前备份 + 写后回读校验）

- 自动检测挂载的相机卡（用 `GetDriveTypeW` 排除**网络映射盘**，避免把含 `DCIM\` 的 NAS 误当相机卡）。
- 推送前先**探测卡是否可写**（真写一个探针文件），并把「新增 / 覆盖 / 跳过」逐条列出让你确认；
  覆盖行会显示卡上将被替换的那条配方长什么样。
- 每次写入都是：**写前把卡上同名文件复制到 `RECIPES\_backup\`** → 写入 → **把文件读回来再解析一遍**，
  值不一致就报错并给出恢复步骤（短写不会在写入时报错，只有回读才露馅）。
- 支持「拉取」（把卡上配方收进 PC 主库）与「恢复备份」；完成后提示**安全弹出**。

### 6. 语言与设置

- 界面内置 **简体中文 / 繁體中文 / English** 三语；首次启动跟随系统语言，切换后重启生效。
- 所有按钮、参数标签、分项评分标签都有**鼠标悬停注释**，没用过的人也看得懂。
- 「设置」里的图像处理方式：**CPU 软解**（默认）；「GPU 硬解」为灰色占位，暂未实现硬件加速。
- 「关于」栏含版权所有人、免费声明（永久免费、严禁售卖）与官方发布页。

## 卡写入是「有备份、可校验」的

往卡上写跟往硬盘上写不一样：短写不会报错（FUSE 层先收下，等到下次读才露馅），而相机 app
遇到读不通的 `.YML` 会**静默跳过**。所以本程序每次推送都是：

1. **写前**：把卡上同名文件复制到 `RECIPES\_backup\`（覆盖前留底）；
2. 写入；
3. **写后**：把文件重新读回来、再解析一遍，值不一致就报错并给出恢复步骤。

推送前会先**探测卡是否可写**（真写一个探针文件），并把「新增 / 覆盖 / 跳过」逐条列出来让你确认。
覆盖前会显示卡上将被替换的那条配方长什么样。失败时提示原文件的备份路径；卡上任何同名文件也能
用「恢复备份」按钮回滚。完成后提示**安全弹出**（先在任务栏弹出该盘再拔卡）。

## 原理与诚实的限制

**前向模型**：用 RL 仓库自带的 77 张标定样片（同一底图 × 77 种配方）做岭回归，学 `参数 → 画面外观`。
留一交叉验证的逐通道 Lab RMSE 约 **5.8**（中位 4.45）。

意味着：

- 拟合结果**方向正确、可作为起点**，但**不是逐像素精确的预览**；
- 预览右侧图对 `cube` 输入是**精确**的（直接套 cube）；对「配方近似」是**参考帧的近似**（真实样片加权混合）；
- 配对反推靠「成片 − 原图」的 Lab 差，把场景本身抵消掉，再叠到参考帧的外观上——所以**两图必须是同一
  机位同一场景**（一次拍两张，或同一张的虚拟副本），否则这个差就不是风格；
- 追色目标作品输入是**跨场景统计近似**——追色目标作品与实际拍摄场景越接近越准；
- 残差栏给出「目标签名 vs 配方预测签名」的 Lab 距离，目标 ≤2。分项栏把这条距离拆成 5 项：明暗（ΔL）、
  饱和（ΔChroma）、冷暖（Δb）、肤色（暖中间调窗口内的 ΔLab）、高光阴影（按参考帧亮度分带后的 ΔL）。
- 置信度 / 校准状态永远是「初始估算（近似，未实机校准）」——模型留一误差约 5.8，是这套离线反推的
  天花板，实机效果仍需上机拍摄验证。

> 这是设计取舍：不额外拍摄标定帧，只用现成 77 帧做离线近似。

## 运行

```powershell
python main.py
```

依赖（已装）：`PySide6`、`numpy`、`scipy`、`scikit-image`、`Pillow`。

首次运行若无 `data\model.npz` 缓存，会从 `data\calib\samples\` 现场回归（约 7 秒），之后秒开。

## 打包成独立 exe

```powershell
python tools\build_exe.py
```

产物是**单个** `RecipeLabStudio.exe`（约 75MB），直接生成在工程根目录，也可复制到任意位置运行。
`library\`（你的配方）与 `settings.json` 会创建在 exe 所在的文件夹里，不在 exe 内部，所以换位置时把它们一起带走即可。
exe 的图标取自 `data\icon.ico`——由 `data\icon.png`（RL fork 卡带未来主义启动图，144px 母版）
经 `python tools\make_icon.py` 生成 16/24/32/48/64/96/128/144/256 九个尺寸；窗口图标用同一张图。

## 出发布包（GitHub Releases）

```powershell
python tools\package_release.py
```

在 `release\` 生成两个文件，都由上面那**一个** exe 打成：

| 文件 | 形态 |
|---|---|
| `RecipeLabStudio-<版本>-portable.zip` | 便携版：解压到一个文件夹即用，配方与设置都写在 exe 旁边，换位置整个文件夹带走 |
| `RecipeLabStudio-<版本>-Setup.exe` | 安装包：单文件、免管理员（装到当前用户）、**先过一页许可声明**、带开始菜单项、可选桌面快捷方式和卸载程序 |

安装包由 Inno Setup 的 `ISCC` 编译（脚本 `tools\installer.iss`，安装界面含简体 / 繁体 / 英文，
中文消息文件在 `tools\isl\`，许可声明在 `tools\license.txt`）。**版本号、版权所有人、仓库地址只写在
`ui\i18n.py`**（`APP_VERSION` / `AUTHOR` / `GITHUB_URL`）：打包脚本会读出来传给安装包，改这三处即可重新出包。

卸载**不会**删除 `library\` 与 `settings.json`——那是你自己的数据，不是安装程序装进去的。

## 值域（越界 = 相机静默跳过该文件，故本地先校验）

| 键 | 范围 |
|---|---|
| `style` | standard / vivid / neutral / portrait / landscape / mono / clear / deep / light / sunset / night / red-leaves / sepia |
| `saturation` `contrast` `sharpness` | −3 .. +3 |
| `effect` | off / toy-camera / pop-color / posterization / retro-photo / soft-high-key / part-color / rough-mono / soft-focus / hdr-art / richtone-mono / miniature / illust / watercolor |
| `white-balance` | auto / keep / 2500K .. 9900K（100K 步进） |
| `amber-blue` `green-magenta` | −7 .. +7（A 为 +，B 为 −；G 为 +，M 为 −） |
| `exposure` | −5.0 .. +5.0，1/3 档（.0 .3 .7） |
| `dro` | off / auto / 1 .. 5 |
| 文件名 | 8.3 大写（名称转大写取前 8 位字母数字）；文件 ≤ 8192 字节；配方名 ≤ 24 字符 |
